# GitHunter Domain Context

## Developer Profile

A public GitHub identity whose observable activity can be measured and ranked.

## Metric Fact

A dated, source-backed observation about a developer, such as merged pull requests, stars received, issues opened, or active repositories.

## Scope Membership

Evidence that a developer belongs to a geographic ranking scope at a particular time.

## Cohort

The eligible set of developer profiles compared within one ranking calculation.

## Lens

A named interpretation of public GitHub work that selects metrics and their relative importance.

## Lens Version

An immutable definition of a lens, including metric weights, transformations, exclusions, and evidence window.

## Ranking Snapshot

A dated, reproducible ranking produced for one scope, cohort, lens version, and evidence window.

## Rank Entry

One developer's position, score, metric breakdown, confidence, and movement within a ranking snapshot.

## Evidence Window

The bounded period from which time-sensitive metric facts are counted.

## Confidence

An explicit estimate of how complete and comparable the evidence is for a rank entry.

## Exclusion

A documented rule that removes ineligible identities or activity from a cohort or metric.
